## 已知环境情况

- 知乎热榜 API 在未登录请求下返回 HTTP 401。
- 知乎回答 API 在未登录请求下返回 HTTP 403 和平台访问限制提示。
- 系统将遵循安全边界：接口模式失败后只尝试用户配置的本地已登录浏览器；登录失效或验证码出现时暂停，不绕过限制。
- 没有配置真实 DeepSeek Key 时，自动化和本地验收使用 Mock Provider；成本记录为 0，不代表真实 DeepSeek 账单。
- 手动图片 Prompt 工作流按产品决定不调用图片 API，图片需要在 ChatGPT 中手动生成后上传。
