# 信息架构

## 主导航

```text
知乎问题总结工作台
├─ 仪表盘
├─ 问题池
│  └─ 问题详情
├─ 任务中心
├─ 草稿审核
│  └─ 草稿详情
├─ 发布中心
└─ 设置
   └─ AI 与模型
```

第一阶段不展示尚未实现的 Prompt 管理、浏览器发布和开源参考独立导航项；相关基础信息集中在设置页，后续阶段再扩展路由。

## 页面层级

| 层级 | 页面 | 主要任务 |
| --- | --- | --- |
| 一级 | 仪表盘 | 了解今日工作量、基础设施和最近任务 |
| 一级 | 问题池 | 查找、筛选、添加、导入和管理问题 |
| 二级 | 问题详情 | 查看元数据、任务、日志、分析结果和草稿 |
| 一级 | 任务中心 | 按状态查看长任务，重试或取消 |
| 一级 | 草稿审核 | 查看由第一阶段结构化结果生成的最小草稿 |
| 二级 | 草稿详情 | 编辑标题和正文，保存新版本 |
| 一级 | 发布中心 | 查看已准备内容和阶段边界，不执行发布 |
| 一级 | 设置 | 查看基础配置、每日计划和浏览器目录 |
| 二级 | AI 与模型 | 切换 Mock/DeepSeek、模型角色并测试连接 |

## 核心页面结构

```text
应用壳
├─ 侧边栏：品牌、主导航、主题切换
├─ 顶栏：页面标题、刷新状态、主操作
└─ 内容区
   ├─ 关键数据/健康状态
   ├─ 筛选与批量操作
   ├─ 主列表或详情
   └─ 可折叠日志/上下文区
```

## 数据与事件流

```text
React 页面
├─ REST：查询、创建和更新
├─ TanStack Query：缓存、错误、刷新
└─ EventSource：任务和基础设施实时事件
      ↓
FastAPI
├─ SQLAlchemy：长期数据
├─ Redis List：任务队列
└─ Redis Pub/Sub：SSE 事件
      ↓
Worker
├─ Provider 服务
├─ 任务状态机
└─ 数据库日志/结果
```

## 响应式策略

- `≥ 1440px`：完整 232px 侧边栏、主表格、右侧日志栏同时显示。
- `1280–1439px`：侧边栏缩到 208px，日志栏可折叠，隐藏低优先级表格列。
- `960–1279px`：侧边栏折叠为图标栏，右侧日志改为抽屉。
- `< 960px`：不是第一阶段主要验收目标；保留可操作的单列布局，不承诺高密度表格体验。

## 导航与可访问性

- 当前路由具有文字、图标和背景三重选中反馈。
- 路由切换后页面主标题获得可感知焦点。
- 所有主要操作可用键盘访问。
- 面包屑只在二级页面出现，避免重复导航。
