# 信息架构

## 主导航

```text
知乎问题总结工作台
├─ 仪表盘
├─ 问题池
│  └─ 问题详情
├─ 任务中心
├─ 草稿审核
│  └─ 草稿详情
├─ 发布中心
├─ Prompt 管理
└─ 设置
   ├─ AI 与模型
   ├─ 浏览器与发布
   └─ 开源参考
```

第三阶段启用 Prompt 管理、浏览器发布和开源参考路由。Prompt 管理进入主导航；浏览器与开源参考作为设置二级路由，避免扩大主导航。

## 页面层级

| 层级 | 页面 | 主要任务 |
| --- | --- | --- |
| 一级 | 仪表盘 | 了解今日工作量、基础设施和最近任务 |
| 一级 | 问题池 | 查找、筛选、添加、导入和管理问题 |
| 二级 | 问题详情 | 查看原始回答、观点地图、来源、任务、模型和费用 |
| 一级 | 任务中心 | 按状态查看长任务，重试或取消 |
| 一级 | 草稿审核 | 查看由第一阶段结构化结果生成的最小草稿 |
| 二级 | 草稿详情 | 编辑文章、审核图片 Prompt/上传图、追溯来源和质量 |
| 一级 | 发布中心 | 检查内容准备、日历排期、发布确认和执行记录 |
| 一级 | Prompt 管理 | 创建新版本、测试、启用、回滚和查看变更 |
| 一级 | 设置 | 查看基础配置、每日计划和浏览器目录 |
| 二级 | AI 与模型 | 切换 Mock/DeepSeek、模型角色并测试连接 |
| 二级 | 浏览器与发布 | 测试本地登录会话、查看安全边界和自动发布开关 |
| 二级 | 开源参考 | 查看依赖、参考项目、版本、许可证和用途 |

## 核心页面结构

```text
应用壳
├─ 侧边栏：品牌、主导航、主题切换
├─ 顶栏：页面标题、刷新状态、主操作
└─ 内容区
   ├─ 关键数据/健康状态
   ├─ 筛选与批量操作
   ├─ 主列表或详情
   └─ 可折叠日志/上下文区
```

## 数据与事件流

```text
React 页面
├─ REST：查询、创建和更新
├─ TanStack Query：缓存、错误、刷新
└─ EventSource：任务和基础设施实时事件
      ↓
FastAPI
├─ SQLAlchemy：长期数据
├─ Redis List：任务队列
└─ Redis Pub/Sub：SSE 事件
      ↓
Worker
├─ Provider 服务
├─ 任务状态机
└─ 数据库日志/结果
```

## 响应式策略

- `≥ 1440px`：完整 232px 侧边栏、主表格、右侧日志栏同时显示。
- `1280–1439px`：侧边栏缩到 208px，日志栏可折叠，隐藏低优先级表格列。
- `960–1279px`：侧边栏折叠为图标栏，右侧日志改为抽屉。
- `< 960px`：不是第一阶段主要验收目标；保留可操作的单列布局，不承诺高密度表格体验。

## 第二阶段三栏工作区

问题详情：

```text
原始回答（筛选、纳入/排除、展开）
│ 观点地图（共识、分歧、少数派、来源）
│ 任务与模型（阶段、Token、费用、日志）
```

草稿审核：

```text
文章编辑器（编辑/预览/版本）
│ 信息图文案与图片 Prompt（复制、上传、纯 CSS、历史）
│ 来源与质量（段落来源、审核项、通过/退回）
```

## 第三阶段工作区

信息图编辑器从草稿审核中间栏打开大尺寸抽屉：

```text
左：模板、画布、标题、结论、观点、字体、品牌、页脚和背景裁切
中：按最终比例实时预览
右：版本、溢出检查、渲染日志和下载
```

发布中心：

```text
内容准备：文章版本、图片版本、审核、风险和加入队列
排期日历：日期、时间、顺序、间隔、方式和冲突
执行记录：状态、最终链接、失败原因、截图、版本和重试
```

Prompt 管理：

```text
左：Prompt 列表和当前启用版本
中：只读生产内容 / 新版本编辑器
右：测试输入、测试输出、参数、历史和审计
```

## 导航与可访问性

- 当前路由具有文字、图标和背景三重选中反馈。
- 路由切换后页面主标题获得可感知焦点。
- 所有主要操作可用键盘访问。
- 面包屑只在二级页面出现，避免重复导航。
