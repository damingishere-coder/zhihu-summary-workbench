# 页面清单

## 第一阶段页面

| 路由 | 页面 | 第一阶段功能 | 关键状态 |
| --- | --- | --- | --- |
| `/dashboard` | 仪表盘 | 今日指标、Redis/Worker/模型/存储状态、最近任务、操作日志 | 加载、空、断连、失败 |
| `/questions` | 问题池 | 标签筛选、搜索、添加、导入、优先级、入队、忽略、删除 | 空、导入部分失败、重复链接 |
| `/questions/:id` | 问题详情 | 元数据、原始回答阶段说明、任务进度、分析结果、日志、重试 | 无任务、运行、失败、已取消 |

| `/drafts` | 草稿审核 | 查看最小草稿及审核状态 | 空、待审核 |
| `/drafts/:id/review` | 草稿详情 | 编辑标题和正文、保存版本、返回问题来源 | 未保存、保存中、保存成功 |

| `/settings/ai` | AI 与模型 | Provider 模式、模型角色、密钥配置状态、连接测试 | Mock 成功、无密钥、超时 |

## 关键页面结构说明

### 仪表盘

顶部为四个紧凑指标和三个主要动作，中部是基础设施健康行，下面是高密度任务表格，右侧为最近操作日志。结构与选定的视觉方案一致。

### 问题池

页面头部提供“添加知乎问题”主操作和“批量导入”次操作。标签、筛选和表格使用同一工作面，不嵌套卡片。行内只保留最高频操作，其余放入菜单。

### 问题详情

标题和外链位于顶部。主体左侧显示描述、示例回答、结构化分析和草稿入口；右侧显示任务阶段、SSE 状态和日志。原始回答区域明确说明第二阶段才进行真实采集。

### 任务中心

以任务表格为主，顶部按状态筛选。失败原因不截断到不可理解；详情抽屉展示完整日志。取消只对运行或排队任务可用。

### 设置

使用纵向分区表单，不使用大量卡片。敏感密钥不回显；只展示“已配置/未配置”。“测试模型”结果就地显示。
