## 第二阶段页面扩展

- `/questions/:id`：原始回答、纳入状态、回答评分、观点簇、观点地图、来源回答、模型用量和任务日志三栏同屏。
- `/drafts/:id/review`：文章编辑/预览、信息图文案、图片 Prompt、手动上传、纯 CSS 模式、段落来源、独立质量审核和审批三栏同屏。

## 关键页面结构说明

### 仪表盘

顶部为四个紧凑指标和三个主要动作，中部是基础设施健康行，下面是高密度任务表格，右侧为最近操作日志。结构与选定的视觉方案一致。

### 问题池

页面头部提供“添加知乎问题”主操作和“批量导入”次操作。标签、筛选和表格使用同一工作面，不嵌套卡片。行内只保留最高频操作，其余放入菜单。

### 问题详情

标题和外链位于顶部。主体左侧显示描述、示例回答、结构化分析和草稿入口；右侧显示任务阶段、SSE 状态和日志。原始回答区域明确说明第二阶段才进行真实采集。

### 任务中心

以任务表格为主，顶部按状态筛选。失败原因不截断到不可理解；详情抽屉展示完整日志。取消只对运行或排队任务可用。

### 设置

使用纵向分区表单，不使用大量卡片。敏感密钥不回显；只展示“已配置/未配置”。“测试模型”结果就地显示。

### 信息图编辑器

编辑器不新增独立路由，从草稿审核中间栏打开。主操作固定为“保存新版本”和“渲染 PNG”，不会覆盖旧版本。实时预览保持 3:4 或规格尺寸比例；超出字符预算时字段、预览和渲染结果同时提示。

### 发布中心

顶部用三个紧凑指标说明准备、已排期和已发布数量，主体使用标签页切换内容表、月历和执行记录。创建排期是唯一主操作；执行前必须在确认框输入指定文字。

### Prompt 管理

生产版本默认只读。点击“创建新版本”后才进入编辑状态，测试和保存分离；启用、回滚均使用二次确认并显示将生效的版本号。
