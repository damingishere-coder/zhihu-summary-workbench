# 回答作者观点调查

2026-09-09：用户明确统计对象为一个知乎问题下的回答作者，不是专栏评论。

成稿顺序：采集和分析范围 → 各观点人数/占比 → 回答里的共性 → 分歧与少数观点 → 样本边界 → 统计图。

统计由 `opinion_survey.py` 根据保存的回答、作者主页和观点来源关系计算，不让模型生成票数。作者主页去重；显示名不作为身份；匿名来源单列。分母为全部已保存回答中可识别的作者数，筛选未通过或没有明确归类的作者仍留在分母，并展示未归类人数。短期内仍沿用现有质量筛选和语义聚类，不能把未分析来源当成已完成归类。

同一观点按作者聚合支持/反对/有条件认同/仅相关提及；同时支持与反对记为混合态度，不重复计票。同一作者可属于多个观点，各观点百分比不要求合计100%。作者未表达某观点，不等于反对。

文章版本冻结统计、原文、作者主页、分析标记和观点关系。文章前置统计段落由程序构建，模型仅归纳原回答的共性与分歧。图片直接读取该文章版本的统计快照，布局编辑保留统计；自动流水线对这类稿件直接渲染数据图，不额外提交背景生图。图片展示支持人数最多的前8个观点并标明展示范围；正文保留全部观点以及支持、反对、条件、混合和仅提及的计数。历史稿件保留原有图片工作流。

验证包含作者去重、同名不同作者、匿名来源、重叠观点、混合态度、未知来源拒绝、零分母、HTML 转义、修改当前来源后图文仍使用原统计快照，以及真实 PNG/发布包链路。

限制：人数计算可复现，语义归类仍依赖 AI；样本未确认完整时不能声称代表全体答主。已完成的旧文章不会自动覆写，需要显式重新生成一个新版本。
